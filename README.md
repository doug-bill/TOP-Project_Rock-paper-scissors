🪨 Rock Paper Scissors – v1.0
A dynamic browser game built with Vanilla JavaScript


🎮 Demo Preview : https://doug-bill.github.io/TOP-Project_Rock-paper-scissors/

🧠 Simple and fast-paced Rock, Paper, Scissors game built from scratch.
Click one of the buttons below to challenge the CPU and see who reaches 5 points first!

📸 Screenshot Placeholder

✨ Features

✅ Fully interactive UI (created dynamically with JavaScript)
✅ Real-time score updates for Player and CPU
✅ Displays round results and move comparisons
✅ Auto-end game at 5 points with replay option
✅ Modular logic for easy refactoring
✅ Clean and readable ES6+ code


🧩 Game Logic Overview
Function	                            Purpose
getComputerChoice(max)	                Randomly selects the computer’s move
playRound(humanChoice, computerChoice)	Determines round winner and updates scores
updateUI(result)	                    Updates DOM elements (result, score, round message)
checkWinner()	                        Detects the game winner and handles replay logic

------------------------------------------------------------------
🧠 How to Play

Choose Rock, Paper, or Scissors using the on-screen buttons.

The computer randomly chooses its move.

Round results and scores update instantly.

First to 5 points wins!

When the game ends, you can restart directly with one click.
